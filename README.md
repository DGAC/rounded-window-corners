<div align="center">
  <h1>PADSI GNOME Shell extension</h1>
  <p><i>Adds colored visual outlines around application's windows</i></p>
</div>
<br>

> [!NOTE]
> This is the fork of the excellent [new rounded-window-corners extension][2] by @flexagoon to add specific PADSI's features.


## Installation

This extension is meant to be packaged with [PADSI][1]'s main package.

## Development

Here are the avaliable `just` commands (run `just --list` to see this message):

```bash
Available recipes:
    build   # Compile the extension and all resources
    clean   # Delete the build directory
    pack    # Build and pack the extension
    pot     # Update and compile the translation files
```
